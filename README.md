# C Programming Practice

Completed Days 1-96 of the C programming curriculum.

- Days 1-50: Questions 1-100 (two solutions per day)
- Days 51-96: Questions 101-146 (one solution per day)
- Total: 96 day folders and 146 standalone C programs

Each solution begins with its official question statement and is named
`Q<number> (Category).c`. The category `Loops without Arrays/Strings` uses a
hyphen in filenames because `/` is not valid in a Windows filename.

Compile an individual solution with:

```sh
gcc -std=c11 -Wall -Wextra -pedantic "Day 1/Q1 (User Inputs, Operations & Output).c"
```
